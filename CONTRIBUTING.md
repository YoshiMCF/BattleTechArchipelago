# Contributing
Contributions are not welcome at the current time. It is too early in the project to coordinate with other people. Contributions will be welcome in the future.

This repo includes a .editorconfig file. Ensure that your text editor reads and abides by the rules in this file. For example, this repo uses K&R style braces:
```
public void Foo() {
    Bar();
}
```
No generative AI (Copilot, Claude, etc.) may be used to contribute to this repo. Pull requests containing AI-generated code will result in user bans. This is your only warning.
